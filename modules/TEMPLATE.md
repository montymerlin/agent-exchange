# [Module title]

## Why this matters

One short paragraph. Why does someone walking into this module care? What does it unlock for them? Avoid abstract motivation — name a concrete situation the reader recognises ("you've been pasting docs into ChatGPT and the context keeps getting lost…").

## What you'll learn

Three to five concrete takeaways, written as outcomes, not topics:

- You'll be able to [X]
- You'll understand the difference between [Y] and [Z]
- You'll have [a working setup / a finished artifact / a working mental model] for [thing]

## What you'll need

Tools, accounts, files, or prior context required to work through this module. Be specific — version numbers, install commands, links. If nothing's needed, say "Nothing — just this file and a working agent host."

## Walkthrough

The core of the module. Keep it concrete. Use real commands, real file contents, real outputs. Break into short numbered or named steps so a participant can pause and resume.

If a step has a "watch out for…" moment, call it out inline rather than burying it in a notes section at the end.

### Step 1: [name the step]

What you do, why you do it, what you should see when it works.

### Step 2: [name the step]

Same shape. Each step should be small enough that "did it work?" has an obvious answer.

## Try it yourself

A short hands-on prompt for the participant to do, not just read. This is what separates a module from a blog post. Examples:

- "Open a folder you already have on your machine. Run [command]. Describe what changed."
- "Take the example above and adapt it to [your own scenario]. Bring the result to the next session."
- "Pair up with someone and walk them through the walkthrough section without looking at it."

## Common pitfalls

Three to five things that trip people up. One sentence each. These are golden — they're the artifacts of having actually taught this module before.

## Takeaway

A single sentence. What's the one thing a participant should walk away saying? If you can't write this in one sentence, the module probably covers too much.
